# Dependency Chart

Dependency Chart is a VS Code extension that converts your project dependencies into an animated interactive pie chart for faster analysis and understanding.

# Usage
1. Install the extension
2. Open any project folder containing a package.json file.
3. Open the VS Code Command Palette: Ctrl + Shift + P
4. Run: Explain Dependency

5. The extension will instantly scan the current project dependencies and generate an interactive animated visualization.

# Features
1. Interactive animated pie chart visualization for project dependencies with smooth buttery transitions and hover interactions.

2. Supports React, Next.js, JavaScript, TypeScript, Angular, Vue, and React Native projects automatically.

3. Smart dynamically generated colors for unlimited dependencies without repeating or hardcoded color limitations.

3. Animated dependency list with package names, percentage contribution, and estimated package sizes.
